# Проверка проекта

## Уже выполнено в Linux

- Компиляция и запуск `tests/CoreTests.cpp` (GCC 11.5, C++20, строгие предупреждения).
- Проверки переходов вперёд/назад, пустого плейлиста, одного трека, выхода за границы.
- Проверки случайного выбора: результат в границах и не повторяет текущий при N > 1.
- Проверки безопасных имён файлов и отклонения обхода каталогов.
- Проверки сигнатур MP3/OGG/WAV/FLAC и отклонения HTML/пустых данных.
- Проверки URL и транслитерации русских названий.
- Сверка используемых деклараций с исходниками SDK и bindings.

Дополнительная попытка запуска с AddressSanitizer/UBSan не состоялась: в среде
нет `libasan.so.6`. Sanitizer-проверка не считается пройденной.

Это не означает, что мод уже скомпилирован под Windows или запущен в GD.

Команда повторного запуска независимых от Geode тестов:

```sh
g++ -std=c++20 -Wall -Wextra -Werror -pedantic tests/CoreTests.cpp -o core-tests
./core-tests
```
