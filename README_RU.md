# Menu Music Player — мод для Geometry Dash

**Статус: исходный проект, НЕ готовый установочный мод.**
Подготовлен под Windows x64, Geode SDK **5.11.2**, Geometry Dash **2.2081**.
Совместимость с исходной GD 2.208 не заявляется. Именно 2.2081 указана в SDK 5.11.2.

Здесь не было доступной Windows-среды с Geometry Dash. Бинарник `.geode` не собран,
в самой игре мод не запускался. Успешная компиляция и игровой тест ещё обязательны.
Архив ZIP нельзя просто переименовать в `.geode` или бросить в папку mods.

## Что реализовано в исходниках

В главном меню добавляется кнопка **MUSIC**. Она открывает плеер:

- **Now playing** — название выбранной музыки меню.
- **Previous / Next** — предыдущая / следующая песня с переходом по кругу.
- **Random** — случайная песня; при наличии двух и более не выбирает текущую.
- **Playlist** — список песен, четыре на страницу; нажми название, чтобы включить.
- **X** — убрать песню из плейлиста после подтверждения.
- **Add song → From file** — выбрать аудио через стандартное окно Windows.
- **Add song → Download** — загрузить по прямой HTTPS-ссылке на аудиофайл.
- **Default** — вернуть обычную музыку меню, не очищая плейлист.

Поддерживаются MP3, OGG, WAV, FLAC размером до **64 МиБ** на файл.
Импортированная песня выбирается и начинает играть. Текущая песня повторяется;
автоматического перехода к следующей в этой версии нет. Плейлист и выбор сохраняются.
Музыка уровней не подменяется. Используется музыкальный канал игры, а не отдельный
фоновый плеер; громкость регулируется обычной настройкой музыки GD.

Интерфейс на английском: стандартные игровые bitmap-шрифты не гарантируют кириллицу.
Русские названия для отображения транслитерируются (например, «Песня» → «Pesnya»),
но исходные названия сохраняются в UTF-8. Другие неподдерживаемые символы заменяются `?`.
Это название из имени файла / поля Song title, а не чтение ID3-тегов.

## Самый простой способ получить `.geode` — GitHub Actions

Не требует установленного компилятора на твоём компьютере. Потребуется аккаунт GitHub.

1. Распакуй этот архив.
2. На GitHub создай новый репозиторий, например `gd-menu-music`.
3. Загрузите **содержимое папки `MenuMusic`** в корень репозитория.
   В корне должны находиться `mod.json`, `CMakeLists.txt`, `src`, `tests` и `.github`.
   Не загружай ZIP как один файл и не создавай дополнительную вложенную папку MenuMusic.
4. Обязательно загрузи `.github/workflows/build.yml`: он запускает сборку.
5. Открой вкладку **Actions → Build Windows mod**. Если требуется, разреши workflows.
   Сборка стартует при добавлении файлов в main/master; её также можно запустить
   через **Run workflow**.
6. Дождись зелёного результата у задания **windows**. Внизу страницы запуска,
   в **Artifacts**, скачай **MenuMusic-Windows**.
7. Распакуй скачанный артефакт. В нём должен быть файл
   `guillotine.menu_music.geode` (имя определяет сборщик Geode).

Если сборка красная: открой ошибочный шаг и пришли текст ошибки или скачанный лог.
Не переименовывай исходный ZIP в `.geode` — это не скомпилирует C++.
Публиковать мод в каталоге Geode или открывать репозиторий для всех ради установки
себе не требуется. Доступность/лимиты Actions определяются твоим аккаунтом GitHub.

### Установка себе после успешной сборки

1. Полностью закрой Geometry Dash.
2. В Steam: Geometry Dash → шестерёнка / Управление → Просмотреть локальные файлы.
3. Открой `geode\mods` в папке игры и положи туда **собранный** файл `.geode`.
4. Запусти игру. Если Geode сообщает о зависимости **Node IDs**, установи её через Geode.
5. Найди кнопку **MUSIC** в нижнем меню. При отсутствии ожидаемого контейнера
   кнопка размещается справа, на высоте 75 игровых единиц от нижнего края.

Не используй одновременно другие моды, меняющие музыку меню: их хуки могут конфликтовать.
При проблемах закрой игру и убери `guillotine.menu_music.geode` из `geode\mods`.
Для первого запуска сделай резервную копию игровых сохранений обычным для тебя способом.

## Как добавлять музыку

### Из файла
MUSIC → Add song → необязательное название → From file → выбрать аудиофайл.
Копия сохраняется в каталоге данных мода, поэтому исходный файл не меняется и может
находиться в папке с русским названием. Отмена диалога ничего не добавляет.

### По ссылке
MUSIC → Add song → вставить URL в поле `https://...` → Download.
Можно указать собственное название в поле Song title. В GD обычно работает вставка Ctrl+V.

Нужна **прямая HTTPS-ссылка на аудиофайл**. Ссылки на страницы YouTube, Spotify,
VK, Яндекс Музыки и обычные страницы файловых хранилищ не подходят. Авторизация,
cookies, обход DRM, извлечение аудио из видео и конвертация форматов не реализованы.
Ссылки с query-параметрами допустимы. URL с логином/паролем внутри не принимаются.
HTTP без TLS не поддерживается. Пользуйся музыкой, которую имеешь право скачивать.

Загрузка идёт в отдельном потоке, порциями по 64 КиБ, без помещения всего файла в RAM.
Лимит 64 МиБ проверяется по реально полученным данным. Проверка сертификатов HTTPS
не отключается; переход с HTTPS на HTTP не допускается. Есть сетевые таймауты,
не более пяти перенаправлений и ограничение длительности передачи.
При закрытии окна операция отменяется (заблокированный сетевой вызов может завершаться
до своего таймаута). Отдельной публикации, передачи файлов другим пользователям,
телеметрии и записи URL в лог код мода не делает.

После импорта проверяются сигнатура файла и возможность декодирования через FMOD.
HTML-страница под видом `.mp3` не добавляется в плейлист. Оригинал `menuLoop.mp3`
не перезаписывается. Файлы из интернета никогда не исполняются.

## Где хранятся данные

Мод использует `Mod::get()->getSaveDir()` и подпапку `tracks`.
Плейлист/выбор сохраняются стандартным механизмом данных Geode, не в игровых уровнях.
Сохранённые аудиофайлы имеют внутренние ASCII-имена. Небезопасные пути из настроек
игнорируются. Временные файлы `.part` очищаются при следующем запуске после сбоя.

Удаление через X убирает только запись плейлиста. Управляемая копия остаётся на диске:
FMOD может держать файл открытым до выхода из игры. Исходные файлы пользователя
никогда не удаляются. Ненужные копии можно убрать из tracks при **закрытой игре**,
но не удаляй файлы, которые ещё используются плейлистом.

## Локальная сборка для разработчика

Нужны Visual Studio 2022 Build Tools с C++, CMake 3.25+, Git, Geode CLI и SDK 5.11.2.
Установи бинарники SDK для Windows по инструкции Geode и укажи GEODE_SDK.
Из x64 Native Tools Command Prompt, находясь в корне проекта:

```bat
cmake -S . -B build -A x64
cmake --build build --config Release
```

Настройка сборки зависит от установленных инструментов; автоматический workflow
предпочтителен для пользователя без настроенной среды. Мод линкуется с WinHTTP,
который входит в Windows. SDK/Geode Loader и чужая музыка в архив не включены.
